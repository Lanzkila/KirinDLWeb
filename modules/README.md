# Modular components

This is the landing area for independently versioned KirinDL Web components.

Following the repository-separation approach used by PipePipe, a component can later be moved to its own repository and added here as a Git submodule.

Do not create a `.gitmodules` entry until the target repository exists and its URL, branch or tag policy, ownership, and license are confirmed. The first scaffold intentionally has no submodules.
